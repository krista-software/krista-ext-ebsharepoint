# EB Sharepoint Extension

Version **1.0.0**

Krista integration with Microsoft SharePoint Online — browse sites, document libraries, folders and
files, and download file content, using Microsoft single sign-on (or a Server-to-Server connection).

See [Overview](pages/overview.md) for what this extension covers, [Extension Configuration](pages/ExtensionConfiguration.md)
and [Authentication](pages/Authentication.md) for how to connect it, and
[Supported requests](pages/supported-requests.md) for the full request index.
